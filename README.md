# 🔎 AI-powered emoji search

Emoji search that uses an LLM to find relevant emojis and playful associations for any query.

## 🛠️ Tech stack

- ☁️ Hono + Cloudflare Workers (API)
- 📦 Cloudflare KV (cache) + Rate Limiter
- 🤖 GPT-OSS 120B on Groq via Cloudflare AI Gateway
- ⚡️ React + Vite
- 🎨 shadcn/ui + Tailwind
